1.14 Phase Capstone

No new teaching content - this lesson is a pure assessment, proving Phase 1's pieces work together and under pressure, not a lecture.

Part A (Build): implement a small "DSA library" module in Python: singly + doubly linked list, array-backed stack and queue, min-heap, hash map with collision handling, BST with insert/search/delete, and a graph with BFS/DFS - all from scratch, no relying on list/dict/heapq/deque internals for the core logic. Write unit tests for each.

Part B (Timed assessment): 6 mixed problems from NeetCode 150, one per major topic (array, linked list, tree, graph, heap, DP), 3 hours, closed-book.

Pass bar: library passes your own unit tests; 5/6 minimum on the timed set. Logged in deferred-exercises.md for the batch practice pass - see that file for the exact checklist.
